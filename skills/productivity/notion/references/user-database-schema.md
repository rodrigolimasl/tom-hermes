# User Database Schema: Controle de Atividades

This document records the specific schema of the user's Task/Activity database in Notion, as discovered in Obsidian checkpoints.

## Database Identity
- **Name:** `Controle de Atividades`

## Properties (Columns)
- `Tarefa`: Title of the task.
- `Status`: Current state of the task.
- `Prioridade`: Priority level.
- `Data`: Due date or date assigned.
- `Labels`: Categorization tags.
- `Empresa`: Company associated with the task.
- `Cliente`: Client associated with the task.

## Allowed Values
- **Prioridades:** `Muito Alta`, `Alta`, `Média`, `Baixa`
- **Status:** `Pendente`, `Em andamento`, `Cancelado`, `Concluído`
