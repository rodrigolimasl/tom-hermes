## Cron Jobs Documentation Format

When a Hermes instance has active cron jobs, create this file so job
definitions survive a full restore (cron jobs live in `state.db` which is
NOT backed up for security).

### File Location

`/opt/data/cron/cron-jobs.md` — this path IS included in the backup
scope (`.md` under `cron/`).

### Template

```markdown
# Cron Jobs — Hermes [AGENT]

Autogenerated or manually maintained. Used for disaster recovery.
Last updated: YYYY-MM-DD HH:MM TZ

---

## Job: [job-name]

- **Schedule:** e.g. `every 2h`, `0 4 * * *` (UTC)
- **Model:** e.g. `qwen3.6:27b` or `anthropic/claude-sonnet-4`
- **Toolsets:** e.g. `[web, terminal, file]`
- **no_agent:** true/false
- **script:** path or "none"
- **prompt:** [copy the full self-contained prompt]
- **deliver:** destination (e.g. origin, telegram:xxx, all)
- **description:** 1-line what this job does
```

### Example

```markdown
# Cron Jobs — Hermes Tom

Last updated: 2026-06-03 03:00 America/Manaus

## Job: backup-hermes

- **Schedule:** `0 4 * * *` (00:00 Manaus)
- **Model:** (none — script only)
- **Toolsets:** (none)
- **no_agent:** true
- **script:** `/opt/data/scripts/backup-tom.sh`
- **prompt:** (none)
- **deliver:** origin
- **description:** Daily backup of operational state to GitHub
```

### Maintenance

Update this file whenever:
- A new cron job is created
- An existing job is modified (schedule, prompt, model, deliver)
- A job is deleted or paused permanently
